## Objetivo do Study Hub

Este repositório funciona como um espaço de organização acadêmica e portfólio. A proposta é registrar a evolução ao longo do semestre, separar os materiais por disciplina e facilitar o acesso às atividades, anotações, resumos, projetos e certificados.
