# Anotações e Resumos — Bootcamp I

Esta pasta reunirá anotações, resumos e materiais de apoio produzidos durante a disciplina.

## Padrão de arquivos

Os arquivos devem ter nomes curtos, sem acentos e com sublinhados no lugar de espaços. Quando houver mais de uma versão, será usada uma numeração, por exemplo:

`Planejamento_Study_Hub_v01.md`
